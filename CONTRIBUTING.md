# Contributing

For a personal copy, fork the project and replace the content in `src/data/profile.json`, `content/` and `public/resume.pdf`. Preserve the MIT copyright notice and upstream attribution.

For code changes, keep the current visual design and static hosting support. Use `withBasePath` for static assets and ordinary links; let `next/link` apply the configured prefix to app routes. Test a project prefix as well as the root path. Run `npm test`, `npm run build` and `npm run format:check`. For browser checks, see README.

Do not submit credentials, raw personal documents, private company assets, node_modules or build caches. Include a short explanation and screenshots for visible changes.
